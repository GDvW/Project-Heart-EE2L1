\chapter{Conclusion}
In conclusion, a system has been developed which localizes the heart valves of a human heart. It consists of three subsystems: a system to model the human heart for testing, a system to preprocess the measured signals and a system to carry out the localization.
The modeling system correctly generates modeled heartbeat signals for six microphones, which also experience relative delays and damping due to the placement of the microphones. There is also an option to add noise and randomization to the signals. 
The preprocessing system analyzes the measurements of each microphone and cuts out only the S1 and S2 peaks of the signals. This is done with a fairly good accuracy.
The system that carries out the localization utilizes a GUI to show the computed location of the heart valves. It does not show the locations correctly in each situation, however in some situations it is fairly accurate. 
The total system is still quite unstable, because it depends on the accuracy of many systems, where one inaccurate component has a profound impact on the output accuracy. One big component that could be improved is the data acquisition, as this was quite noisy.
Overall, we have a system that works in mostly ideal cases. However, more research should be done on how the system can be made more robust.
