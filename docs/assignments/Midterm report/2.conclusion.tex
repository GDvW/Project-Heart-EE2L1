\chapter{Conclusion}
In conclusion, almost everything was implemented in a way such that it meets the requirements. However, for some signals, the classification algorithms from module 1 do not work. Also, the heart model is very slow in generating data with random parameters, which is necessary to conduct more realistic tests. 
For module 3 and 4 every algorithm works and has been thoroughly tested. The only problem was that the setup for the recordings this year was not ideal. There was probably a lot of noise and signal reflections, causing inaccurate measurements and results.
